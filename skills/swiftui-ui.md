# SwiftUI UI Guidance

- Prefer standard navigation, lists, forms, buttons, menus, sheets, system colors, SF Symbols, and emoji avatars.
- Keep views focused and extract reusable rows, status badges, and state controls.
- Support Dynamic Type without fixed text heights or clipped labels.
- Verify light and dark mode, accessible contrast, and narrow iPhone layouts.
- Provide VoiceOver labels, hints where useful, and text or symbols in addition to color.
- Add stable accessibility identifiers to critical controls used by UI tests.
- Run and inspect the app in an available iPhone Simulator before delivery.
